# 🛒 무인 마트 관제 대시보드 (Smart Mart Control UI)

## 📌 프로젝트 개요
본 프로젝트는 **ROS2 기반 무인 마트 물류 자동화 시스템**의 전체 현황을 모니터링하고 제어하는 **관리자용 데스크톱 관제 애플리케이션**입니다. 
빠르고 안정적인 데이터 처리를 위해 **PyQt5** 프레임워크를 기반으로 개발되었으며, **`rclpy`**를 통해 ROS2 네트워크와 네이티브로 연동됩니다. 
전체 UI는 크게 **대시보드(Dashboard), 비전(Vision), 임무 주문(Ops)** 3개의 페이지로 구성되어 단일 화면에서 시스템의 모든 상태를 통합 관리할 수 있습니다.

<br/>

## ✨ 주요 기능 (Key Features)

### 1. 🗺️ 동적 맵 렌더링 및 로봇·장애물 관제
* **실시간 맵 시각화 및 트래킹**: 그리드 맵 위에 작동 중인 터틀봇(AMR)들의 실시간 위치를 오버레이로 표출합니다.
* **장애물 노드 관리**: 맵 상의 장애물을 감지하여 노드 차단 알람을 띄우고, 오버레이로 시각화 및 제거 버튼을 통해 즉각적인 대응이 가능합니다.

### 2. 🎥 다채널 비전 카메라 스트리밍 (Vision Page)
* 비전 전용 페이지를 통해 로봇 주행 카메라 및 창고 검수용 고정 비전 카메라 등 다채널 영상 데이터를 실시간으로 모니터링합니다.

### 3. 📋 임무 주문 및 작업 큐 (Ops Page)
* **임무 상태 시각화 및 제어**: 대기 중, 진행 중, 완료된 작업 목록을 관리하고, 새로운 물류 임무(Task)를 로봇에 직접 할당하거나 스케줄링할 수 있습니다.

### 4. 📦 DB 및 ROS2 통신 실시간 연동
* 창고의 보관 슬롯 등 주요 상태 정보를 데이터베이스와 연동하여 최신 상태로 렌더링합니다.

<br/>

## 🛠 기술 스택 (Tech Stack)
* **GUI Framework**: Python, PyQt5
* **Robotics Middleware**: ROS2 (rclpy)
* **Integration**: PostgreSQL (DB 연동)

<br/>

## ⚙️ 핵심 기술 및 아키텍처 (Technical Highlights)

* **rclpy 기반 ROS2 네이티브 통신 및 스레드 분리**
  * 대량의 ROS2 토픽 데이터(/robot_status 등)를 수신할 때 메인 GUI가 멈추는(Freezing) 현상을 방지하기 위해, **통신 전담 스레드와 UI 스레드를 분리**했습니다.
  * `rclpy` 노드에서 수신한 데이터를 PyQt의 **`시그널-슬롯(Signal-Slot)`** 방식을 통해 메인 UI 위젯들로 안전하고 비동기적으로 전달하여 화면을 갱신합니다.

<br/>

## 📁 디렉토리 구조 (Directory Structure)
관제 UI 소스코드는 기능별 분리 원칙에 따라 모듈화되어 있습니다.
```text
smart_gui/
├── __init__.py      
├── main.py            # 애플리케이션 진입점 (장애물 노드 차단 알람, 맵 오버레이 및 통합 로직)
├── map_view.py        # 맵 렌더링, 로봇 마커 및 장애물 오버레이 위젯
├── ops_page.py        # 임무 주문 및 작업(Task) 관리 페이지
├── vision_page.py     # 다채널 비전 카메라 모니터링 페이지
├── panels.py          # UI 구성을 위한 공통 위젯 및 패널 모듈
├── theme.py           # GUI 테마 및 스타일 설정
├── ros_link.py        # rclpy 기반 ROS2 노드 통신 및 데이터 처리 모듈
├── db_link.py         # DB 상태 연동 모듈
└── camera_link.py     # 카메라 영상 스트리밍 연동 모듈
```

## 🚀 실행 방법 (Getting Started)

### 1. 사전 요구사항 (Prerequisites)
* 메인 관제 서버 및 네트워크 환경이 구동 중이어야 정상적으로 데이터를 수신할 수 있습니다.
* Python 3.8 이상의 환경이 필요합니다.

### 2. 패키지 설치
관제 UI를 구동하기 위해 필요한 패키지를 설치합니다.
```bash
pip install PyQt5 requests
```

### 3. 프로그램 실행
소스 코드가 있는 폴더로 이동하여 메인 프로그램을 실행합니다.
```bash
cd src/S_Mart/smart_gui
python3 main.py
```
