# 🛒 무인 마트 관제 대시보드 (Smart Mart Control UI)

## 📌 프로젝트 개요
본 프로젝트는 **ROS2 기반 무인 마트 물류 자동화 시스템**의 전체 현황을 모니터링하고 제어하는 **관리자용 데스크톱 관제 애플리케이션**입니다. 
웹 브라우저의 제약에서 벗어나 빠르고 안정적인 데이터 처리를 위해 **PyQt** 프레임워크를 기반으로 개발되었습니다. 
시스템 네트워크와 연동하여 다중 로봇(AMR)의 이동 좌표, 창고 보관 상태, 작업 내역 및 비전 카메라 영상을 단일 화면에서 통합 모니터링할 수 있습니다.

<br/>

## ✨ 주요 기능 (Key Features)

### 1. 🗺️ 동적 맵 렌더링 및 로봇 트래킹
* **실시간 노드 맵 시각화**: 4x4 그리드 맵 위에 작동 중인 터틀봇(AMR)들의 위치를 마커로 오버레이 표출합니다.
* 로봇의 주행 경로와 현재 진입한 노드 상태를 직관적으로 파악하여 모니터링합니다.

### 2. 🎥 다채널 비전 카메라 스트리밍
* **화면 스위칭 기능**: 로봇 전방에 부착된 주행/도킹용 카메라와 입고장에 설치된 고정형 검수 카메라 영상을 드롭다운 메뉴로 전환하여 모니터링합니다.

### 3. 📦 창고 슬롯 현황판
* 냉장 및 냉동 창고의 보관 슬롯 상태를 직관적인 격자(Grid) UI로 렌더링합니다.
* 물품 적재 상태 데이터에 따라 해당 슬롯의 하이라이트 표시가 실시간으로 갱신됩니다.

### 4. 📋 작업 큐(Task Queue) 및 종합 로그
* **임무 상태 시각화**: 대기 중 / 진행 중 / 완료된 작업을 분리하여 타임스탬프 기반 시스템 로그로 표출합니다.
* 로봇이 현재 어떤 미션(예: 입고 적재 중, 출고지 이동 중 등)을 수행하고 있는지 텍스트 및 상태 표시줄로 명확히 보여줍니다.

<br/>

## 🛠 기술 스택 (Tech Stack)
* **GUI Framework**: Python, PyQt (PyQt5)
* **Data Parsing & UI Updates**: JSON 통신 데이터 파싱 및 시그널-슬롯 기반 화면 갱신

<br/>

## ⚙️ 핵심 기술 및 아키텍처 (Technical Highlights)

* **멀티스레딩 적용 (UI 프리징 방지)**
  * 대량의 상태 데이터 및 카메라 스트리밍 영상을 수신할 때 메인 화면이 멈추는(Freezing) 현상을 방지하기 위해, **데이터 수신 스레드와 메인 UI 스레드를 완벽히 분리**했습니다.
  * PyQt의 **`시그널-슬롯(Signal-Slot)`** 방식을 적용하여, 백그라운드 스레드에서 데이터를 안전하게 수신한 뒤 메인 UI의 컴포넌트들을 비동기적으로 업데이트하도록 설계했습니다.

<br/>

## 📁 디렉토리 구조 (Directory Structure)
```text
smart_gui/
├── main.py                # 애플리케이션 진입점 및 GUI 초기화
├── dashboard_window.py    # 메인 관제 대시보드 화면 레이아웃 설정
├── map_view.py            # 동적 맵 렌더링 및 로봇 마커 표출 위젯
├── threads/
│   └── status_worker.py   # 백그라운드 데이터 수신 및 처리 스레드
└── utils/                 # 설정(settings.py) 및 유틸리티 함수
```

## 🚀 실행 방법 (Getting Started)

### 1. 사전 요구사항 (Prerequisites)
* 메인 관제 서버 및 네트워크 환경이 구동 중이어야 정상적으로 데이터를 수신할 수 있습니다.
* Python 3.8 이상의 환경이 필요합니다.

### 2. 패키지 설치
관제 UI를 구동하기 위해 필요한 패키지를 설치합니다.
```bash
pip install PyQt5 requests
```

### 3. 프로그램 실행
소스 코드가 있는 폴더로 이동하여 메인 프로그램을 실행합니다.
```bash
cd src/S_Mart/smart_gui
python3 main.py
```
